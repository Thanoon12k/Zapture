Privacy, simply.

This website

This landing page has a small first-party visit counter. It stores only an aggregate total on our server, without IP addresses, fingerprints, or visitor identifiers. A first-party cookie named zapture_visit contains the date of your visit and expires after one day. It prevents repeat visits from the same browser from increasing the total on the same UTC day. This is an approximate count of daily browser visits, not unique people. Deleting cookies, using another browser, or visiting on another day can increase the count. The GitHub badge only reads the total and does not count badge impressions. We use no advertising trackers or sign-up forms. The interactive recorder is a simulation: it never requests screen or microphone access.

The site is hosted by PythonAnywhere. Like other web hosts, it may process technical request logs, including IP addresses, for hosting and security. Fonts load from Google Fonts, which receives the request metadata required to serve them. Downloads and documentation link to GitHub, whose own privacy terms apply.

The desktop app

Zapture saves screenshots and recordings on your computer. It does not include telemetry, accounts, or automatic cloud upload. You choose what to capture and where to save it.

AI and MCP

MCP is optional. When you connect a local MCP client, that client can request captures. Your chosen AI client may send images to its own service. Review that client's settings and privacy policy before connecting it.

Questions

You can open an issue on GitHub. Do not include private recordings, credentials, or sensitive personal information in public issues.
